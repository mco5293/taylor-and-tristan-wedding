# Taylor & Tristan — wedding website

## Upload to your existing GitHub Pages repository
Extract the ZIP and upload the files INSIDE this folder to the same location as
your current index.html. Replace index.html, styles.css, and script.js. Keep your
existing assets folder. Do not put the whole extracted folder inside the repository.

Pages:
- index.html — hero, countdown, and Our Story
- the-day.html — four-stop timeline and venue details
- wedding-party.html — ten bridesmaids and ten groomsmen
- travel.html — travel information and FAQs
- registry.html — registry information
- rsvp.html — RSVP information

All pages share styles.css and use relative links for GitHub Pages project sites.
The navigation is repeated in each HTML file; edit all six headers if you change it.
The stylesheet has one consolidated set of component styles and responsive rules.

## Photos (keep these in your existing assets folder)
The source attachments contain code only, so the ZIP does not include your photos:

File names are case-sensitive. Portrait instructions are in wedding-party.html.
The repeated Logan McDannell cards are preserved from your supplied HTML; replace
those placeholders with the remaining groomsmen when you have their details.

## Editing
Our Story: index.html. Venues/times: the-day.html. Party: wedding-party.html.
Hotel/transportation/FAQs: travel.html. Registry: registry.html. RSVP: rsvp.html.
Uncomment the example registry or RSVP button and insert its real URL when ready.
The .button styles support those currently commented examples.
The calendar download is an all-day save-the-date with the supplied venue details.
The countdown uses Pennsylvania calendar days and does not scroll the page.
No build step is needed. Google Fonts requires an internet connection; local
fallback fonts are provided. To preview navigation locally, open index.html.
